# Cycle+ par Happy Mum's

Application web de santé menstruelle pour les filles et les jeunes femmes d'Afrique, de 9 à 30 ans. Gratuite, en français et en anglais.

https://cycleplus.netlify.app

## Ce que fait Cycle+

- Suivre ses règles (début, fin) et voir les prochaines dates prévues
- Noter sa journée en moins d'une minute : humeur, énergie, douleur, flux
- Comprendre ce qui se passe dans son corps selon la phase du cycle
- Poser ses questions à Binta, une grande sœur virtuelle, même sans connexion pour les questions fréquentes
- Savoir quand consulter, avec une page d'aide et des numéros utiles selon le pays
- Vérifier les idées reçues sur les règles avec le Détecteur de mythes

## Vie privée

Les données du cycle et du journal restent sur le téléphone de l'utilisatrice. Aucun compte n'est demandé. Binta ne reçoit ni le prénom ni les notes personnelles.

## Hors connexion

Une fois ouverte avec internet, l'application fonctionne aussi sans réseau.
